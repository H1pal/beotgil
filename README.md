# 벗길

대구 달성군의 휠체어 이용자를 위한 이동 및 대피 내비게이션 시제품입니다.

## 실행

Python 3에서 카카오 REST API 키를 환경변수 `BEOTGIL_KAKAO_REST_KEY`로 설정한 다음 `python3 beotgil-server.py`를 실행하고 `http://localhost:8081/`에 접속합니다. 카카오맵 JavaScript 키에 해당 도메인을 등록해야 합니다.

현재 경로는 카카오맵 일반 도보 경로입니다. 경사로, 계단, 단차 및 재난 위험 정보는 연결되지 않았습니다.

지도 아래의 **현재 지도에서 계단·경사로 찾기** 버튼은 현재 화면 범위의 OpenStreetMap 데이터를 Overpass API에서 조회합니다. 목록이나 지도 표시를 선택하면 등록된 정보를 확인할 수 있습니다. 정보가 없는 구간의 접근성은 확인되지 않았으며, 이 정보는 현재 도보 경로 계산에 적용되지 않습니다.

건의 사항은 서버의 `beotgil-data.sqlite3`에 저장되며 최근 50건이 표시됩니다. 도착지와 이름이 일치하는 OpenStreetMap 장소의 휠체어 태그가 있으면 안내합니다. 자료가 없으면 확인 필요로 표시합니다. 서버에 저장된 내용을 볼 수 있는 사용자는 건의 내용도 볼 수 있습니다. API는 `docs/suggestions-api.md`를 참고하세요.

도보 예상 시간이 10분 이상이면 대중교통 및 자동차 예상 시간을 각각 조회할 수 있습니다. 카카오맵 대중교통 API와 카카오모빌리티 자동차 길찾기 API 이용 설정 및 REST API 키가 필요합니다. 교통수단별 휠체어 이용 가능 여부는 제공되지 않습니다.

도보 안내는 처음 5개 구간을 표시하고 나머지는 펼쳐 볼 수 있습니다. 도보 10분 이상 시 대중교통 또는 자동차 시간을 조회하면 해당 경로가 지도에 각각 파란색 또는 빨간색으로 표시됩니다. 카카오 API에서 좌표를 제공하지 않는 경우 시간만 표시합니다.

건물 편의시설 정보는 공공데이터포털 `한국사회보장정보원_장애인편의시설 현황`의 일반 인증키를 `BEOTGIL_PUBLIC_DATA_KEY` 환경변수로 설정해야 조회됩니다. 시설명과 좌표가 일치하는 결과만 표시합니다. 시설 정보는 휠체어 통행 가능을 보장하지 않습니다.


선택한 출발지와 도착지는 이 브라우저에 저장할 수 있고, 최근 선택한 장소 10개를 다시 사용할 수 있습니다. 저장 장소는 기기별로 관리됩니다. 도착지 편의시설 정정 요청은 `beotgil-data.sqlite3`의 `facility_corrections` 테이블에 검토 대기 상태로 저장되며, 공공데이터를 자동으로 수정하지 않습니다. 관리자는 SQLite에서 해당 테이블을 조회할 수 있습니다. API는 `docs/facility-corrections-api.md`를 참고하세요.


지진 옥외 대피장소를 보려면 재난안전데이터 공유플랫폼의 해당 API 서비스키를 서버 환경변수 `BEOTGIL_SAFETY_DATA_KEY`에 설정하고 서버를 재시작합니다. `지진 대피장소` 버튼으로 달성군 장소를 표시합니다. 현재 위치에서 가까운 후보 5곳의 일반 도보 시간을 비교하며, 휠체어 접근성·현재 위험·실제 운영 여부는 반영되지 않습니다. 자세한 API는 `docs/earthquake-shelters-api.md`를 참고하세요.

구지읍 통합대피소는 `BEOTGIL_INTEGRATED_SAFETY_KEY` 환경변수로 연결합니다. 지도에서 한파·무더위 쉼터, 지진 옥외·지진해일 긴급 대피장소를 구분해 선택할 수 있습니다. 시설 운영 상태와 휠체어 접근성은 확인되지 않습니다. API 설명은 `docs/integrated-shelters-api.md`를 참고하세요.

로컬에서 통합대피소 키를 안전하게 보관한 경우, 서버 실행 전에 `export BEOTGIL_INTEGRATED_SAFETY_KEY="$(cat ~/.config/beotgil/integrated-safety-key)"`를 실행해 설정할 수 있습니다. 카카오와 기존 공공데이터 키도 각각 기존 환경변수에 설정해야 합니다. 이 파일은 저장소에 포함하지 않습니다.

학교 주변(위도 35.638~35.688, 경도 128.383~128.444)의 계단·경사로 조회는 2026-11-20 기준 Geofabrik 대한민국 OpenStreetMap 추출본에서 관련 태그가 있는 지점과 길을 추출해 화면에 저장한 자료를 사용합니다. 해당 범위에서는 계단·경사로 태그가 있는 지점과 길이 0건이었습니다. 자료가 없다는 뜻이며 통행 가능하다는 뜻은 아닙니다. 범위 밖은 기존 Overpass API를 사용합니다. 데이터 출처 © OpenStreetMap 기여자, ODbL. 시간이 지나면 자료를 갱신해야 합니다.

도보 결과의 보행로 정보는 카카오 안내문에서 계단, 육교, 지하보도, 에스컬레이터가 언급된 구간을 표시하고, 경사로·단차 등 확인되지 않은 항목을 안내합니다. 학교 주변 저장 자료 적용 여부와 기준일을 함께 표시하며 안전한 휠체어 경로를 판정하거나 우회 경로를 계산하지 않습니다.

계단·경사로 지도에는 달성군 육교정보에 등록된 응암육교(위도 35.654524, 경도 128.417041)의 점자블록·경사로 정보를 별도로 표시합니다. 자료 기준일은 2026-06-24이며 실제 통행 가능 여부는 확인되지 않았습니다. 일반 도보 경로가 시설 좌표로부터 약 35m 이내인 경우 주변 시설로 안내하며 육교 진입이나 사용을 판정하지 않습니다. 출처: https://data.daegu.go.kr/open/data/dataView.do?dataSetId=15025444&dataSetDetailId=1502544418d86ab39541c_201909241018&provdMethod=FILE
